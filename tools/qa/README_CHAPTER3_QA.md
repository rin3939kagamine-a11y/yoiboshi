# 第3章 統合QA — 正式CSS・実戦・スマホ表示

対象: 『宵星の契約者 RE:START』の最新GitHubチェックアウト。

## 実行方法

ローカルPCで Python、Playwright、Chromium を用意し、リポジトリルートで実行します。

```bash
python -m pip install playwright
python -m playwright install chromium
python tools/qa/chapter3_integration_smoke.py
```

システムにChromiumがあればそれを利用し、見つからない場合はPlaywrightに同梱されたChromiumを使用します。

## 検査範囲

- 実際の `index.html` が指定する全JavaScriptと、正式 `css/styles.css` を同一のブラウザページへ読み込む。
- 320×568、375×667、390×844、430×932、1280×800の会話UI。左右の余白、会話タイトルと操作ボタン、会話欄との重なり、横スクロールを検証する。
- 第1～2章を完了したテスト用セーブから、第3章のq13～q18を順番に進める。
- 各依頼の導入イベントを正式処理で読了、調査の完了状態を用意して、従来型・ターン制AUTOの戦闘エンジンで実際に敵を倒す。
- q14後のサキ・ユズ・ちよ、q15後の玲子・あんず、q16後のなずなの出会いを実行して、解放条件を検証する。
- q17のボス演出中はAUTOが一時停止する仕様に従い、表示された演出をクリックして再開する。無理に戦闘を即時終了させない。
- 各依頼の初回報酬、後日談、最終章エピソードを確認する。

## 制限

- 第1～2章のクリア履歴・育成済み編成はテスト用にセットしている。**新規セーブから全5章を連続プレイした試験ではない**。
- 第3章の調査パートは `phase:'ready'` のセーブをセットしている。調査操作・謎解きは未検査。
- ブラウザのHTML/CSS/JS確認であり、iPhone実機・Safari検証ではない。
- 画像・音声の全素材が実ファイルとして揃っているかは検査していない。
- 高レベル編成による戦闘経路であり、初期レベル・通常育成の勝率は証明しない。

当初のローカル検証では旧CSSのため会話ボタンが未装飾で重なって見えていた。正式CSSで再現せず、別に発見した物語全画面UIの左右余白をCSSで修正した。

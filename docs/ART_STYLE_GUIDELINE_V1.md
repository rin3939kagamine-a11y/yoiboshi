## 2. 目標画風：「柔らかい中間アニメ調」

| 項目 | 採用する基準 | 避ける表現 |
|---|---|---|
| 顔 | 自然な顔の立体感。鼻・口は控えめ、輪郭は上品。キャラごとに目の形・顎・頬・眉を描き分ける | 写真風の肌・過度に大きい目・全員同じ顔 |
| 年齢感 | 各キャラの設定年齢と印象を優先。大人を不必要に幼児化しない | 誰でも童顔化、または一律に成熟した顔にする |
| 線画 | 細め～中程度の整理された線。境界は読みやすく、硬すぎない | 漫画のような極太線、線が消えるほどの写実塗り |
| 肌 | なめらかな下地＋穏やかな明暗差。頬や鼻筋には必要最小限の血色 | 毛穴・実写テクスチャ、強いテカり、過度な頬染め |
| 目 | 虹彩は繊細で透明感がある。ハイライトは控えめ | 星・グリッターだらけの瞳、過剰な反射 |
| 髪 | 髪束の流れに沿った自然な艶。輪郭と主要な束が読み取れる | 髪の一本ずつの写実描写、極端な金属光沢 |
| 衣装 | 生地の種類が分かる程度のしわ・陰影。既存の装飾は厳守 | 勝手なフリル・ベルト・宝石・露出の増減 |
| 光・影 | 落ち着いた光、柔らかいグラデーションと必要なセル影の併用 | 過度のコントラスト、映画的に強すぎるリムライト、3Dレンダリング風 |
| 色彩 | やや落ち着いた彩度。キャラ固有色は正確に維持 | 全体を一律にくすませる、ネオン・発光の追加 |
| 背景 | キャラと同じ2Dイラスト空間。適度な空気遠近感 | 背景だけ写真・3DCG、キャラだけ浮く仕上がり |

**共通キーワード**：日本のノベルゲーム向け、繊細で自然、柔らかな光、上品で落ち着いた色彩、適度な立体感、2Dイラストとしての統一感。

## 3. 人物同一性は共通画風より優先する

1. **固定**：顔の形、目の色・形、髪色・髪型・分け目、髪飾り、衣装の基本構造・色、体格、設定年齢。
2. **許可**：表情、目線、手の動き、体の向き、構図、自然な光の変化、場面上必要な髪・服の揺れ。
3. **要確認**：私服への着替え、髪をほどく、重要な装飾を外す、衣装の大きな変更、既存設定にない身体的特徴。
4. **禁止**：他キャラの造形の混入、別人化、無断の衣装改変、肌の露出増加、設定と不整合な年齢変更。
5. 顔を似せるために他人の顔をコピーしない。**「人物の一意性を守りながら仕上げの画風を揃える」**。

## 4. 素材種類ごとの制作規格

### A. 会話用立ち絵
- 正面～軽い斜め向き、姿勢は自然。演技用の腕・手の位置を確保。
- 顔と頭頂を絶対に切らない。指定範囲（全身／太ももまで等）を守る。
- 背景は無地か透過。余計な小物・風景を生成しない。
- 作品内の立ち絵と線密度・顔の描き方・影の柔らかさを合わせる。
- 元画像と視点・頭身・衣服の覆う範囲を維持。**必要のない再デザインをしない**。

### B. 表情差分
- **同一人物、同一服装、同一頭部の位置・大きさ・カメラ距離**で制作。
- 表情は `通常／微笑／悲しみ／怒り・不満／驚き／照れ` を基本セットとして、キャラ性格に合わせ強弱を調整。
- 顔だけを変えることを原則とし、髪・飾り・服の変化は避ける。特に目の形が別人化しないこと。
- 画像サイズ・背景・切り抜き位置・命名規則は既存素材の構造に合わせる。

### C. イベントCG
- 標準想定は**横長16:9**。スマホ横向きで人物が切れないように重要要素を中央寄りの安全範囲に収める。
- 画面下部には会話UIが重なる可能性があるので、顔・重要な手元・決定的な小物を下部に密集させない。
- **感情を説明する絵でなく「行動を通じて伝える絵」**にする。視線、手の動き、二人の距離、姿勢を重視。
- キャラは立ち絵と同じ共通画風。背景もやや柔らかい2Dに統一。光源の方向を人物と背景で一致させる。
- 演出はシナリオに登場するものだけ。魔法光・粒子・鳥・花びら・余計な人物・文字を勝手に足さない。
- 1場面につき**まず1枚だけ試作**。採用確定まではゲームに自動組み込みしない。

### D. 戦闘用ちびキャラ（別規格）
- 既存の2頭身、全身、背景透過、左右の向き、太めで読みやすい輪郭を優先。
- 通常立ち絵の頭身・線の細さを無理にちびキャラへ適用しない。
- 髪型・衣装の色・固有装飾を抽出して、縮小しても誰か分かるようにする。

## 5. 画像生成の事前確認ゲート

次のチェックを**すべて満たした場合だけ生成する**。

- [ ] 用途（立ち絵／表情差分／CG／ちび）が確定した
- [ ] キャラID・名前と、**現在の正式立ち絵の参照画像**がある
- [ ] シーン名、登場人物、感情、必要な動作が分かる
- [ ] 画角・構図・画面に入れる範囲が決まっている
- [ ] 衣装・髪型など固定事項を明文化した
- [ ] **追加禁止事項**（人物、小物、特殊効果、文字など）を記載した
- [ ] 既存本編の秘密をCGで先に漏らさない
- [ ] **生成枚数は1枚**。ユーザーから複数枚の指示がない限り増やさない

不明点があっても、勝手な演出や飾りを足して埋め合わせない。必要なら**生成前に確認する**。

## 7. 完成品QA（採否を分ける）

**必須ゲート：いずれか失敗なら修正または作り直し**

1. **同一人物性**：既存の顔、目、髪、装飾、衣装が一致する。
2. **画風整合**：ももか・みるくの線画、肌、目、陰影、色の「仕上げ方」に揃っている。
3. **脚本整合**：場所、行動、表情、登場人物、ネタバレのタイミングが正しい。
4. **構図**：顔・手・頭頂・足など、用途に必要な部分が切れない。
5. **余計なものなし**：追加指示のない小物・人物・文字・エフェクトがない。
6. **表示QA**：スマホ縦／横でUIと重ねて確認できるまで実装完了とはしない。

**採用ステータス**：`参考案` → `試作` → `作画監査合格` → `ゲーム組込` → `ブラウザQA合格` → `正式採用`。段階を飛ばさない。

## 8. 今回の判断と適用範囲

- **固定する方針**：ももか・みるく基準の「柔らかい中間アニメ調」。キャラの個性は維持。
- **未実施**：全キャラの絵柄変換、既存立ち絵の上書き、イベントCGの再生成、新CGの実装、iPhone Safari実機QA。
- 既に制作された凪の観覧車CGは**比較用の試作**として扱う。人物同一性・画風・スマホ表示を確認するまでは正式CGとして扱わない。
- **変更管理**：このガイドを更新する場合は Ver.2 を作り、基準画像・変更理由・従来画像への影響を明記する。

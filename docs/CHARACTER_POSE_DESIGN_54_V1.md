## 1. 結論：同じ6ポーズは作らない

すべての人物に6つの完全別ポーズを割り振る方式は採用しない。顔だけ切り替えてもよい通常会話と、仕草まで変える場面を分ける。共通の分類名を使用しながら、**動作の中身はキャラごとに固有**とする。

| レイヤー | 意味 | 使用条件 | 基準 |
|---|---|---|---|
| **P0 通常** | 既存衣装の基本立ち絵。表情だけの変化も可能 | 通常会話、初期交流 | 現行画像の同一性を維持 |
| **P1 感情** | その人に特徴的な一つの仕草。例：ペンを引く・カメラを下ろす | 強い怒り、不満、悲しみ、驚き、照れ等で必要時のみ | P0と**顔の位置・見かけの大きさを合わせる** |
| **P2 特別** | 弱さ・決意・関係の変化が出るシーン専用カット | 該当する個別交流・本編の開示後のみ | 既存ストーリーの事実とネタバレの時期を優先 |

`normal / smile / pout / sad / surprise / blush` の既存6表情キーを保持。**「笑顔=必ずP1」などの全員共通自動規則は作らない**。P1使用の候補表情は個別表の「P1候補」を参照。P2は表情キーで自動的に出すのではなく、**シーンIDと段階**で判定する。

| `smile` | P0で口元・目元を変える | 体の動きが感情を伝える場面だけ | 自動表示しない |
| `pout` | P0の眉・口元の不満 | 叱る・威嚇する・考え込むなど、性格に合う仕草が必要ならP1 | 自動表示しない |
| `sad` | P0で視線・眉・口元を変える | 肩の力が抜ける・手を引く・振り返る等ならP1 | 自動表示しない |
| `surprise` | P0で目・口元を変える | 明確な身体反応があればP1 | 自動表示しない |
| `blush` | P0で視線・頬・口元を変える | 手元で隠す・顔を背ける等、その人らしければP1 | 自動表示しない |

### 代表例：早瀬真琴（`concept15`）

- **P0**：書類を抱え、ペンを体側で保持。`normal` と軽い `smile` は同じ立ち姿を利用。
- **P1**：ペンを差し出す手を引き、相手を見てから目を伏せる。`pout` や `sad` の強い場面でだけ使用。
- **P2**：夜の市役所で書類を机に置き、初めて仕事ではない遠回りを提案する。これは立ち絵の単純な差分ではなく、個別交流演出として扱う。
- **禁則**：6表情すべてペンを突き出す・毎回書類を差し出す・30歳の年齢感を変える。現行の真琴新画像2枚は**採用候補**。直近の6枚生成画像には透明縁のノイズがあり、無審査で正式採用しない。

### 代表例：白峰凪（`nagi`）

- **P0**：軽く横向きで相手を視線だけで確認。
- **P1**：半歩引き、肩越しに相手を見る。`sad` や `pout` の強い場面。
- **P2**：港で背を向けたまま去ろうとして、立ち止まり振り返る。**秘密の開示前に感情の理由を絵で先出ししない**。

## 4. 制作フロー：画像を作る前に守る

1. **参照を固定**：対象キャラの現在の全身・上半身・通常顔と、絵柄基準のももか・みるくを確認する。キャラIDを正確に指定する。
2. **まずP0の必要性を判断**：既存立ち絵を維持できる場合は新規生成しない。既に試作済みのキャラは採用待ち素材を再利用する。
3. **P1は一度に1枚だけ試作**：姿勢の変更が有効な会話だけを指定し、既存の顔・目・髪型・衣装の同一性を最優先する。不要な文字・人物・小物は禁止。
4. **P0/P1の顔位置校正**：顔中心、頭頂位置、肩幅、実寸表示と透明余白を一致させる。差分切替で顔が飛ぶ場合はNG。
5. **感情を強くし過ぎない**：`sad` は全員が泣くわけではない。`pout` は全員が怒鳴るわけではない。性格に沿った弱い表現を許容する。
6. **P2は物語の段階確認が先**：キャラ本人の秘密、過去、正体、関係性に応じて、表示タイミングをシナリオ担当が承認してから作る。個別イベントCGと立ち絵を同一視しない。
7. **画面QA**：390×844、568×320、844×390、1280×800で会話UIをテスト。文字の上に顔・手元が重ならないこと。iPhone実機は別途検証。
8. **段階的に採用**：P0→P1→P2の順に品質ゲートを通過。画像パスが確定するまでは既存の表情素材を削除しない。
